# Deviations from the pre-registration and the protocol

Every way the study as run differs from what `docs/study-design.md` fixed in advance: the
pre-registration (§7, fixed before collection), the protocol (§2, §4, §8), and the proposal
(`paper/sources/`) where it matters to a reader. The confirmatory tests ran once, on 2026-11-11,
after commit a83471a (20:57 that day). "Before" and "after" in the table are relative to that run.
The paper's deviations table (Table 6 in `paper/outline.md`) is drawn from the first section here.

Qualitative-report items rest on an AI-assisted first pass that has not been spot-checked. They are
marked [UNVERIFIED] until it is (qualitative report §8). This file names no participant except 19,
whose deviation `docs/study-design.md` already records.
